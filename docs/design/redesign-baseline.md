# WRC 小程序重设计基线（2026-09-29）

## 已选方向

- 视觉稿：[首页方案 1](home-reference.png)。核心顺序为品牌、今日打卡、跑量、挑战、次要入口。
- 微信小程序为正式实现目标，先改会员首页与共用底部导航；其他业务页面保持可进入，后续逐页迁移视觉样式。
- 首页服务的主要任务：记录今天的跑步。团跑报名、挑战、个人数据和兑换为后续路径。管理员入口继续按现有角色显示。

## 数据与交互约束

| 视觉稿区域 | 实际数据来源 | 空状态 |
| --- | --- | --- |
| 今日打卡 | 导航到 `pages/clockdaily/clockdaily` | 页面沿用现有登录流程 |
| 本周跑量 | `user/getWeekRuleList` 的 `sport_total`，逐日汇总；按 50 公里统一参考目标计算进度 | 提示登录后查看，不编造个人成绩 |
| 连续打卡 | `user/getserialday` 的 `serialDay` | 0 天或登录提示 |
| 累计跑量 | `user/getsportinfo` 的 `totalDistance` | 不显示伪造值 |
| 当前挑战 | `acty/getchallengeacty` 中用户已参加且进行中的挑战 | 引导去挑战列表 |

视觉稿中的 `28.6/50 公里`、`70%`、`87/120 公里` 等个人成绩是设计示意，不代表当前用户数据。首页恢复了视觉稿中的周跑量进度条：50 公里明确标为全站统一的**每周参考目标**，不是用户自行设定的目标；跑量与百分比由本周实际记录计算。访客和接口失败时不显示示意成绩。

## 视觉规范

- 背景暖白，主要文字深松绿，重点操作荧光黄绿；次要文字保持足够对比。
- 以间距、字级和分隔线组织内容，减少装饰卡片和渐变。
- 首页保留真实头像与跑团动态；新标识为从原 `images/logo.png` 衍生的设计资产。
- 导航图标来自 Google Material Icons 官方开源资源，见 [图标说明](https://google.github.io/material-design-icons/)。

## 验收范围

- 首页在微信开发者工具常见手机视口无横向溢出、底栏遮挡或首屏入口缺失。
- 打卡、团跑、挑战、我的、跑团动态、资讯、兑换、管理员入口可按原业务路径到达。
- 登录与未登录均有真实的可理解状态；接口失败时不显示设计稿示意数据。
- 比对选中视觉稿与模拟器截图，记录差异；真机及生产后端验收单独标记。

## 分阶段实施

1. **首页与共用导航**：先把方案 1 落在小程序首页，让记录跑步、团跑、挑战、个人数据都能从新界面到达。当前代码已覆盖这一阶段；访客路径已在开发者工具验证，详见项目根目录 `design-qa.md`。
2. **记录跑步和个人数据**：打卡入口与“我的”首屏已统一视觉、访客状态和关键字段；已登录图表、上传识别及提交流程待运行态验收。见 [一级页面设计](primary-pages.md)。
3. **团跑与挑战**：一级列表已统一视觉与加载状态；详情、报名和管理员流程待继续迁移与验收。见 [一级页面验收记录](primary-pages-qa.md)。
4. **服务与内容**：整理兑换、资讯、跑友动态等次要页面，保持真实数据和原业务路径。

每阶段同时检查访客与已登录状态、常见手机视口以及已有业务入口。视觉稿中的个人成绩只作为排版示例。

## 现有工作区
