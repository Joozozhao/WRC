# WRC 一级页面重设计与开发进展（2026-09-30）

## 视觉与架构基准

延续选定的首页方案 1（docs/design/home-reference.png）设计语言：
- **配色**：暖白底（#fbfcf9）、深松绿信息层（#072f27 / #0b503b）、荧光黄绿操作层（#d9ff3f，文字深绿 #062b23）。
- **微排版**：大号加粗排版、手绘倾斜下划线、细分隔线（1rpx solid #e1e9e3）、纯白卡片（#ffffff，圆角 24rpx，边框 1rpx solid #e3ebe4）。
- **底栏收敛**：底部导航严格收敛为 4 个一级页面（首页、团跑、挑战、我的），移除悬浮打卡，打卡收敛至首页 Hero 胶囊。
- **资讯清理**：资讯模块彻底从 app.json、首页、管理后台及全局样式中剥离。
- **统一顶部栏**：四个一级页面共用暖白自定义顶部栏；左侧为品牌标识与头像，垂直位置与右侧微信原生胶囊对齐。顶部栏提供统一的松绿圆形返回箭头，供采用自定义导航的页面复用。

2026-10-01：四个一级页面接入 `components/site-header/`；团跑、挑战、我的改用自定义导航，以便沿用与首页一致的品牌区和胶囊安全间距。团跑详情、挑战详情也接入同一组件的主题返回键；返回堆栈为空时分别回到对应列表页。

2026-10-01（列表卡片）：团跑与挑战列表卡片改为海报满铺版式——封面图铺满整卡，正文区用「透明到暖白」的纵向渐变承托文字，海报不再被硬裁切，底部文字区自然过渡。管理操作（编辑/删除，V挑战含加规则/删规则）收进右上角白色胶囊悬浮层，仅 `管理员` / `管理员/团长` 可见；挑战卡片的「上榜/下榜」功能已失效，连同 `toTop`/`upTop` 与相关接口调用一并移除。

- **打卡记录列表**（pages/recordlist/recordlist）：导航栏与页面底色对齐暖白，筛选浮层现代化，跑步卡片微排版与状态指示，一键审核悬浮胶囊。
