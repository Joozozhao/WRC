# 我的页面：可选时间范围的跑步打卡热力图

## 本轮需求与设计约定
用户提供 GitHub contribution 图作为布局参考，要求默认最近半年；右上角下拉可选最近 1、3、6、12 个月。标题为「最近 X 月跑步打卡 N 天」。

- 保留位置：本月跑量卡片紧下方。
- 图外标注月份、周一/周三/周五及少→多的绿色色阶；格子内不展示日期或具体公里数。
- 用户补充：范围选择仅显示文字和小箭头，不使用边框、底色或圆角外框。保留透明触控区。
- 排版补充：左侧标题与右侧范围文字底部对齐，缩小标题到下方图表的间距；标题及打卡天数使用 300 字重，其余区域文字使用 100 字重。
- 方格补充：所有 1/3/6/12 个月范围统一使用 18rpx 方格与 6rpx 间隔。短范围自然留白，不放大或拉伸；长范围横向滚动。
- 移动端较长时间范围支持图内横向滑动，月份标注与色块共同滚动，星期标注固定。默认显示最新记录一端。
- X 为选中月份数；N 为范围内正跑量日期数，同一天多条记录只计一天。沿用现有统计口径：排除已驳回，待审核与已通过计入。
- 连续滚动 X 个日历月，截至当天；目标月份没有同日取月末，再加一天作起点。未来及首尾补齐格不计入天数。
- 切换范围复用当前用户本次加载的日跑量，不重新请求历史列表。未完成请求期间切换，返回后按最新选择展示。
- 游客、加载中和加载失败不能假称零天；标题使用「—」，数据失败可重试。

## 验收清单
- 默认 6 个月；下拉含 1、3、6、12 四项，选择状态和标题一致。
- 四个范围的起止边界、跨年、闰年月末、唯一打卡天数以及范围外记录排除。
- 月份标注位置、首尾月份与跨年月份无明显重叠，星期与网格行对齐，方格与色阶正确。
- 6/12 月水平滚动、最新端默认定位、1/3 月宽度适配，无页面横向溢出。
- 选择范围无需网络；请求未完成时选择有效；重复刷新、切换用户及退出丢弃旧数据。
- 保留积分、小花儿、打卡、兑换、个人资料与其他服务。
