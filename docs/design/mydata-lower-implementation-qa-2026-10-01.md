# 「我的」下半页设计与验收（2026-10-01）

## 最终布局

沿用现有暖白底、深松绿与荧光黄绿主题。下半页依次呈现常用服务、马拉松成绩和参与记录。

- 常用服务采用一体化白卡列表，普通跑友显示三项，管理员按既有角色条件显示第四项。每行补充用途说明，保留原入口。
- 马拉松成绩采用分隔行，赛事名称最多两行；类型与日期允许换行；右侧净成绩和说明分别成行。「查看全部成绩」放在章节标题旁。
- 挑战、团跑记录采用横滑卡片。海报和合影完整按比例显示，名称、日期放在图片下方；缺少图片时显示文字占位。
- 参与记录组件使用页面已有的左右边距，取消重复内缩。末尾导流卡随同排卡片拉伸，页面底部保留导航与安全区空间。
- 下半页辅助说明使用 200 字重；跑量摘要与热力图的现有数据口径、统计范围和加载状态保持原实现。
