# 「我的」页二次重设计（2026-10-01）

## 设计目标

沿用 WRC 首页已确定的暖白、深松绿和荧光黄绿视觉规范。首屏聚焦跑者身份、本月跑量与常用操作，减少重复卡片；较少使用的日历、成绩和参与记录保留在下半页。

## 页面结构

1. **头部与身份信息**：头部沿用团跑、挑战页的英文标识、两行大标题、荧光短线与说明文字；其下展示头像、姓名和跑者 ID，整行可进入个人资料。
2. **跑步摘要**：深松绿主卡突出本月跑量，本周运动、连续打卡与累计跑量作为三项辅助数据。接口未完成或失败时显示「—」，不把默认 0 当作真实成绩。
3. **资产与服务**：积分、小花儿合并为一张双栏资产卡；打卡记录、我的兑换、兑换好礼和按角色显示的跑团管理改为清晰的分隔行。
4. **跑步日历、成绩、参与记录**：日历保留月份切换，并区分加载、成功和失败；成绩与参与记录继续展示接口数据。
5. **访客状态**：显示身份引导、登录按钮及团跑/挑战入口，不展示需要登录的资产与私人记录。
