# 运动月报保存到相册：后台配置

2026-10-30 在 WRC 微信开发者工具中复现：海报已生成，`getImageInfo` 成功读取为 750 × 1000 JPEG；`saveImageToPhotosAlbum` 返回：

```json
{"errno":112,"errMsg":"saveImageToPhotosAlbum:fail api scope is not declared in the privacy agreement"}
```

这是本地开发版运行时返回的错误，说明当前被测环境没有识别到该接口声明；它本身不能证明正式版指引缺失，也不能代替平台的提审失败原因。

截图显示当前指引已包含“相册（仅写入）”。建议把该信息类型的用途改成下面这句，使用途和运动月报的保存功能对应：

> 仅在你主动点击“保存图片”后，将本小程序生成的运动月报图片保存到你的设备相册。

后台对应接口为 `wx.saveImageToPhotosAlbum`，小程序授权范围为 `scope.writePhotosAlbum`。平台隐私声明与用户授权是两项独立条件；修改 `app.json` 不能代替后台声明。

前端已补充隐私授权检查、errno 112 提示、拒绝相册授权后的设置引导与重试，并记录原始失败信息。修复提示不代表平台限制已解除。

修改后请根据微信公众平台提示提交并等待生效。若提审仍失败，应以平台返回的具体原因逐项修订，不要仅凭保存接口的 112 错误推断提审失败原因。生效后请在微信真机重新打开月报，点击保存、同意必要授权，确认图片实际写入相册；分别检查两种月报设计。开发者工具的图片生成成功不能代替真机保存验收。
